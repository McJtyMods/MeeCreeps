# MeeCreeps

MeeCreeps for Minecraft 26.2 and NeoForge 26.2.0.75 or later. Requires Java 25. The One Probe is optional; the tested release is `26.2_neo-15.0.1-2`. Interaction Wheel integration is disabled because it is unavailable for 26.2. McJtyLib `26.2-10.0.0.2` or later is required and supplies command routing, shared packet helpers, and world-data support.

Set `JAVA_HOME` to a Java 25 **JDK**, then build with `./gradlew build`. Install `build/libs/meecreeps-26.2-4.0.1.jar` in your Minecraft 26.2 NeoForge instance. The project uses NeoGradle 7.1.38 and Gradle 9.2.1, matching the Multi_neo workspace.

Run a development client with `./gradlew runClient`. The `mcjtylib()`, `top()`, and `jei()` build helpers include McJtyLib, The One Probe, and JEI for development. Use `./gradlew runServer` for a dedicated development server.

The build uses `gradletools.gradle` from the root workspace, a local standalone copy, or the parent directory when present, otherwise from the MultiWorkspace `26.2_neo` branch. While that branch is unpublished, copy `../Multi_neo/gradletools.gradle` into a standalone checkout and exclude `/gradletools.gradle` in `.git/info/exclude`. Workspace projects supply McJtyLib and The One Probe when present. Generate client or server data with `./gradlew runClientData` or `./gradlew runServerData`; both write resources to `src/generated/resources`. For integrated playtesting, use `:workspace:runClient` or `:workspace:runServer` from Multi_neo; project-qualified tasks such as `:MeeCreeps:runClientData` remain available. Use `./gradlew publishMod` to publish the beta release with `CURSEFORGE_TOKEN` and/or `MODRINTH_TOKEN` set. Publishing declares McJtyLib as required and The One Probe as optional.

Run the 23 integration tests with `python3 scripts/run-gametests.py` or `./gradlew runGameTestServer`. The One Probe and JEI are included in development test runs. Tests cover transactional energy charging and rollback, persistence and component synchronization, cartridge recipes and remainders, action networking and ownership checks, entity saves, portal expiry and aimed height, cross-dimension teleportation, protected harvesting, crop replanting, moving a chest with its inventory, chest animation, lighting, building around obstructions, and material shortage feedback. Test sources and structures are excluded from the release jar.

Portal guns and cartridges accept NeoForge energy: 1,000 FE equals one portal charge. Cartridges can also be charged with ender pearls. Cartridge insertion/removal preserves destinations and partial FE charges. Sneak-use the portal gun on a block to manage its eight destinations; Delete removes the selected destination. This built-in destination screen works without Interaction Wheel. The message-repeat key defaults to B.

Commands: `/meecreeps list` (operator), `/meecreeps clear` (your tasks), and `/meecreeps clear all` (operator). Legacy `/creep_list`, `/creep_clear`, and `/creep_test` command names are available.

This port uses data components for item charge, destinations, and cube history, registry-aware item serialization for carried inventories and saved tasks, and the 26.2 render-state APIs for entities, portals, and GUIs. Existing 26.2 registry names, item components, portal data, and the `meecreeps:actions` task save layout are preserved. Worlds from older Minecraft versions have not been migration-tested.
